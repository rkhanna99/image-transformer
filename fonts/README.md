# Metadata export fonts

Original keeps the existing Times fonts. The new Pillow renderers use the bundled static TrueType files below and do not depend on browser or operating-system fonts.

- `plus-jakarta-sans/`: Plus Jakarta Sans Regular, Medium, SemiBold, and Bold, from the [official Tokotype repository](https://github.com/tokotype/PlusJakartaSans/tree/master/fonts/ttf).
- `jetbrains-mono/`: JetBrains Mono Regular, Medium, and SemiBold, from the [official JetBrains repository](https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/ttf).

Each directory includes its upstream `OFL.txt` license. Font files were bundled on 2026-11-13. Keep the font files and their license together when distributing the application.
